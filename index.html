Trigger to handler, in practice

Triggers stay thin and hand off to a handler class, so logic is testable, reusable and easy to follow.

  • One trigger per objectThe trigger only routes context to the handler.
  • Collections, not recordsHandlers take lists and maps so every method is bulk-safe.
  • Easy to testBusiness logic is covered directly in handler test classes.
